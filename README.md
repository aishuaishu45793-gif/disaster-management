# 🌍 Disaster Management System

A web-based **Disaster Management System** designed to help users access disaster-related information, emergency resources, safety guidance, and response support through a centralized platform.

## 📌 Project Overview

Disasters such as floods, earthquakes, cyclones, fires, landslides, and other emergencies can require quick access to reliable information and emergency resources.

The **Disaster Management System** provides a centralized platform where users can find disaster information, safety instructions, emergency contacts, and other useful resources. The project aims to support **disaster preparedness, emergency response, and public awareness**.

## 🎯 Objectives

* Provide quick access to disaster-related information.
* Help users understand different types of disasters.
* Provide emergency and safety information.
* Improve disaster preparedness and awareness.
* Make important emergency resources easier to access.
* Provide a simple and user-friendly interface during emergency situations.

## 🚨 Disaster Types

The system can provide information and safety guidance for different disasters, including:

## ✨ Key Features

### 🏠 Dashboard

A centralized dashboard for accessing important disaster management features and information.

### 🚨 Emergency Information

Provides quick access to emergency-related information and resources.

### 📚 Disaster Awareness

Contains information about different disasters, their causes, risks, and preventive measures.

### 🛡️ Safety Guidelines

Provides safety instructions for before, during, and after different types of disasters.

### 📞 Emergency Contacts

Helps users access important emergency contact information.

### 📍 Disaster Response

Supports users in understanding appropriate actions during emergency situations.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/aishuaishu45793-gif/disaster-management.git
```

### 2. Open the Project

```bash
cd disaster-management
```

### 3. Install Frontend Dependencies

Navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the frontend:

```bash
npm start
```

### 4. Backend Setup

Open another terminal and navigate to the backend directory.

For Python projects, create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the backend:

```bash
python app.py
```

> The exact commands may vary depending on your project's actual frontend and backend configuration.
